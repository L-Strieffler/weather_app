# Weather App

A simple and modern Flutter weather app that displays current weather details and a 7-day forecast in a clean, user-friendly interface.

## Features

- **Current Weather**: See the current temperature, humidity, pressure, and wind speed for your selected location.
- **7-Day Forecast**: Scrollable forecast cards show the day of the week and min/max temperatures.
- **Location Display**: Clearly shows the selected city at the top.
- **Responsive UI**: Clean, minimal design that adapts to different screen sizes.
- **Easy Navigation**: Tap on a day in the forecast to view detailed weather data for that day.

## Project Structure

- `lib/` - Main application code
  - `features/weather/domain/entities/` - Weather data models
  - `features/weather/presentation/widgets/` - UI components
  - `features/weather/presentation/pages/` - App screens
- `test/` - Widget and unit tests
